芋づる写真館（Imozuru）公開ベータ利用条件
制定日: 2026-10-20
提供者: astromory

1. 対象と利用許諾
本条件は、提供者が配布する芋づる写真館の公開ベータおよび検証用バイナリに適用します。
公開ベータは、個人・法人、非商用・商用を問わず、無料で利用できます。
利用する端末へのインストール、および自身の利用のためのバックアップを認めます。
アプリ本体のソースコードは非公開です。本条件によってソースコードの提供を約束するものではありません。
正式版の料金・利用条件は未定です。正式版の方針は別途案内します。

2. 改変と再配布
第5項の例外を除き、アプリ本体の実行ファイル、インストーラーその他のバイナリを改変すること、
および改変したバイナリを配布することを禁止します。
アプリが用意する設定変更、通常のインストール・更新、およびキャッシュの削除は、
ここでいうバイナリの改変には含みません。
未改変のバイナリを第三者へ再配布する場合は、事前に提供者へ相談し、明示の許可を得てください。
無償のミラー配布・ファイル共有、および有償の再配布もこの対象です。
公式配布ページへのリンクによる紹介は、事前の許可なく行えます。

3. ベータ版の提供と更新
初回の公開ベータは Windows 11 x64 向けです。初期ベータはコード署名を行っていません。
macOS 版は当面、検証協力者向けの検証用ビルドです。Developer ID 署名・公証は行っていません。
対応形式・既知の制限は利用ガイドと各版のリリースノートを確認してください。
自動更新はありません。公開済みの配布ファイルは差し替えず、修正版には新しいバージョンを付けます。
公開ベータには不具合が残る可能性があります。

4. 問い合わせ
不具合・要望・再配布の相談は、公式リポジトリの GitHub Issues で受け付けます。
回答・修正の実施や、その期限は約束しません。
Issues の内容は公開されます。個人の写真・氏名を含むパス・秘密情報は記載しないでください。

5. 第三者ソフトウェアと法令上の権利
同梱・利用する第三者ソフトウェアには、それぞれの権利者が定めるライセンスが適用されます。
本条件の改変・再配布の制限は、それらのライセンスが認める第三者ソフトウェアの利用、
複製、改変、ソースコードの取得、再配布等の権利を制限しません。
第三者ソフトウェアについて本条件とそのライセンスが矛盾する場合は、当該ライセンスを優先します。
適用される法令によって制限できない権利についても、本条件によって制限するものではありません。
第三者ソフトウェアのライセンス文・著作権表示・ソース取得先は、
同梱の THIRD-PARTY-NOTICES.txt およびアプリ内ヘルプを参照してください。
